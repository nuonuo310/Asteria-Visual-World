# Asteria Visual World — 视觉状态与暂定锁定项

> 更新：2026-09-17  
> 性质：视觉工程工作记录。这里区分“暂定锁定”“原型占位”“仍待决定”，避免以后把试验稿误当成最终设计。

## 1. 当前总方向

Asteria Visual World 是共同生活空间的可视化层。Home 看见正在发生的生活，Mind 感受此刻，Memory 观察过去。当前阶段优先把结构、层级、手机端比例与交互逻辑做对，再逐步替换正式素材、动画和真实数据。

共同原则：

- 手机端优先，页面允许纵向滚动，不为了塞进一屏删内容。
- 轻、透、留白，但不能因为留白造成模块彼此断开。
- 少边框、低饱和、同源视觉元素；避免“功能仪表盘”感。
- 具体数值/解释默认不抢画面，需要主动点击时再出现。
- Home / Mind / Memory / Chat / Detour 使用同一套底部悬浮胶囊导航。
- 各页面字号、标题层级、正文密度以 Home 的比例作为统一基线。

## 2. 系统配色：当前三套预览

原 moodboard 的 01 与 04 太接近，因此暂时去掉 04「纯净奶白」，保留三套差异更明确的浅色系统主题。它们是系统外部底色，不改变 Mind 花自己的驱动力色系。

| Theme | 名称 | 主底色 | 雾色 | 状态 |
| --- | --- | --- | --- | --- |
| 01 | 珍珠暖白 / Pearl Warm White | `#FBF8F6` | `#FDEFF3` | 当前默认预览 |
| 02 | 雾粉柔白 / Misty Pink White | `#FDF6F8` | `#FBE8F0` | 当前预览 |
| 03 | 紫灰柔白 / Lavender Gray White | `#F8F6FA` | `#ECE6F3` | 当前预览 |

配色约束：

- 底色始终保持高明度，首先读成“白”，再感到轻微色相。
- Mind 主框必须比页面外部背景再向前一层：略浅、略亮，但不能变成明显白卡片。
- 三套主题切换只换外部空间与 UI token；Mind 花不跟着整套换色。
- 最终仍会继续微调“紫底时框是什么颜色”等表面关系，目前三套主要用于真实页面对比。

## 3. Mind 花：已锁定的颜色逻辑

Mind 花不是三套不同配色。母版 / A / 07 的比较最终确认它们仍属于同一颜色家族，只是浓度、轻重和扩散方式不同。

当前锁定颜色家族：

- 粉
- 雾紫
- 浅蓝
- 暖杏金

状态变化通过浓度、扩散、聚拢、透明度、流动等表达，不通过更换整套 hue family 表达。当前 CSS 中的具体 hex 只是排版原型近似值，不视为正式色值锁定。

## 4. Home 模板：暂定锁定

当前 Home 结构方向已经成立，后续以“装修”而不是推翻骨架为主。

### 顶部与关系区

- 顶部只保留 Asteria 字标为视觉中心。
- 关系照片/纪念日区域作为页面上部关系封面。
- 照片支持本地导入、移动、缩放、文字换边；编辑控件默认收起。
- 日历承接在关系区下方，默认收起，需要时展开完整月历。
- 头像/照片与纪念日强调共同生活，不做厚重外框和竖分隔。

### 留言与生活入口

当前暂定模板采用：

- 留言区：左侧一张主要留言，右侧两个等宽小单元。
- 生活入口：Shen / Nuo / Letters / Diary / Studio，同一条轻量区域内排列。
- 新内容只用小红点等轻提示，不把入口做成彩色功能宫格。

### 今日足迹

- 放在生活入口下方，页面自然向下滚动。
- 记录每天少量真正值得留下的生活事件，不做流水账。
- 不重复信件/日记本身的通知内容。
- 当前原型使用左侧连续竖线 + 轻卡片；文字、卡片厚度仍可继续收轻。

## 5. Mind 模板：暂定锁定

当前结构顺序：

1. Asteria 顶部状态
2. Mind 主框与花
3. Mind 与“此刻的我”之间的轻触区
4. 此刻的我
5. 三个等大平排详情入口
6. 最近变化
7. 固定底部导航

页面可滚动，不要求一屏看完。

### Mind 主框

- Mind 自己有独立圆角框，不是整个页面共用一个大框。
- 主框比外部页面略浅、略亮，形成一层很轻的前后关系。
- 花是视觉主体，不在自然状态下常驻四个驱动力文字。
- 点击花的对应区域后，才浮出该区域的名称、当前值、变化量与一句很短的趋势说明；点击空白关闭。
- 这个轻读数只负责“让我看懂眼前这朵花”，不替代「四个驱动力」详情页。

### 此刻的我

- 是当前整体状态/一句话摘要，不是四驱读数解释。
- 保持比 Mind 主框明显更矮，避免成为第二个大主视觉。
- 可保留少量状态 tag，但不堆数据。

### 三个详情入口

固定为三个同尺寸、同权重入口：

- 四个驱动力 / Drives
- 即时状态 / States
- 我们之间 / Between Us

入口只表达“这是一个可进入的总类”，不在首页展开内部四项。元素必须同源、低饱和，不能用四个不同彩色功能图标制造抢眼宫格。进入详情页后再在同一详情页面内部切换具体项。

### 轻触区

当前占位为三个横排动作：

- 想你
- 戳戳
- 抱抱

只保留中文短词，不放长英文说明。位置暂定在 Mind 与“此刻的我”之间，用来收住两块之间的空隙。正式元素和最终交互语义仍待后续挑选。

### 最近变化

功能定位：展示 Mind 整体近期变化摘要，不重复四驱详情页的单项趋势。

当前折线仅用于比较排版。已知问题是大框 + 少量数据容易显空，底部堆一串文字也不好看。因此此模块 **尚未锁定视觉形式**。下一轮优先比较更矮的折线摘要、节点内嵌短标签等方案，不扩大信息量来硬填空间。

## 6. 当前实现进度

- Home：结构原型已存在，三套系统浅色主题已接入。
- Mind：结构原型已存在；主框、轻触区、此刻的我、三入口、近期变化均已进入同一手机页面。
- Mind 花点击读数：已做交互占位，默认隐藏，只在点击对应花区时出现。
- Home / Mind：主题选择写入同一个本地主题键，两个页面共用 01 / 02 / 03。
- 正式 Mind 花资产：未接入当前排版页；现在的模糊花只用于验证位置和层级。
- Memory：独立视觉工程继续按 Memory Nebula 路线推进，不在本仓库此轮排版中改动。

## 7. 下一轮装修清单

- 用正式 Mind 花替换排版占位花。
- 继续校准 Mind 主框与三套外部底色的前后层级。
- 为「想你 / 戳戳 / 抱抱」挑统一的小元素并验证是否保留该位置。
- 重新比较“最近变化”的高度、折线密度和标签方式。
- 三个详情入口继续找同源元素，不使用不同色功能图标。
- Home 与 Mind 持续统一字号、间距、圆角、边框透明度和底栏比例。
