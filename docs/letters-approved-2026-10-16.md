# Letters 视觉确认版 · 2026-10-16

糯糯已确认信匣、读信页与待启封信封的当前视觉。

- 入口：`letters.html`；读信：`letter.html`；写信草稿：`letter-write.html`。
- 普通信封使用完整 `assets/letter-envelope-v5.png`，读信使用完整 `assets/letter-paper-v4.png`，不拆分或拉开上下资产。
- 待启封信封使用 CSS 结构、透明装饰和普通信封同款的坐姿双熊 `assets/letter-bears-cover-v3.png`；寄存文字以信封居中。
- 待启封交互可切换等待与到期示例，点击到期信封展开与普通读信页相同的信纸。
- 已包含轻压反馈、信纸淡入、筛选淡入、未读点呼吸；尊重减少动态效果设置。
- 普通信件支持作者筛选、搜索、每页六封分页；写信按钮放在列表下方。

当前仍是视觉与浏览器交互示例：三封普通信和一封待启封示例；草稿及阅读状态仅保存在当前设备的 localStorage。未接入正式寄信、跨设备存储、服务器日期校验、定时投递或 Home 到期提醒。示例中的日期不代表已寄存真实信件。
